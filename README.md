# Диагностика ПТСР по малоканальной сухой ЭЭГ

Репозиторий команды bokom-m. Решение задачи классификации и оценки выраженности фенотипа ПТСР по 6-канальной сухой ЭЭГ (NeuroPlay-6C).

## Данные и постановка задачи

Входные данные: 6-канальная ЭЭГ (O1, T3, Fp1, Fp2, T4, O2), частота дискретизации ~125 Гц.
Для каждого испытуемого записано 6 файлов в формате EDF:
- `T-П.edf` — фоновая запись покоя с закрытыми глазами (~60 с);
- `T-1.edf` ... `T-5.edf` — пять последовательных сессий решения таблиц Шульте с открытыми глазами.

Целевая переменная: вероятность принадлежности к группе ПТСР в диапазоне [0, 1].

Основные группы:
- Контроль (норма): 67 испытуемых;
- ПТСР: 25 испытуемых (клиническая верифицированная когорта);
- Соматоформные расстройства: 74 испытуемых (контроль специфичности).

Валидация решения проводится строго по испытуемым (GroupKFold / Leave-One-Subject-Out) во избежание утечки данных между сессиями одного человека.

## Структура проекта

- `model/`
  - `model.py` — функции load, predict, run для инференса модели организаторами;
  - `requirements.txt` — зависимости Python.
- `results/`
  - `1-exploration.ipynb` — первичный анализ сигналов, спектров и поведенческих маркеров;
  - `2-preprocessing.ipynb` — фильтрация, извлечение признаков и обучение моделей;
  - `3-model-inference.ipynb` — расчет итоговых метрик (ROC-AUC с bootstrap 2000, Balanced Accuracy);
  - `4-confounders-specificity.ipynb` — анализ специфичности на соматоформных расстройствах и контроль возраста;
  - `5-bonus.ipynb` — извлечение компонентов вызванных потенциалов (MMN, P3a) на девиантный стимул.
- `docs/` — регламент ТЗ, протокол сбора данных и литература.
- `download_data.py` — утилита для скачивания обучающего датасета из S3.

## Установка и запуск

Python 3.12.7. Установка зависимостей модели:
```bash
pip install -r model/requirements.txt
```

Для ноутбуков и тестов:
```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest
```

Загрузка обучающего датасета:
```bash
python download_data.py
```

Инференс на тестовой папке:
```python
from pathlib import Path
from model.model import load, run

model = load(Path("model/weights"))
run(model, input_dir=Path("test_data"), output_path=Path("predictions.csv"))
```
