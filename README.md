# Диагностика ПТСР по малоканальной сухой ЭЭГ

Репозиторий команды bokom-m. Решение задачи классификации и оценки выраженности фенотипа ПТСР по 6-канальной сухой ЭЭГ (NeuroPlay-6C).

## Данные и постановка задачи

Входные данные: 6-канальная ЭЭГ (O1, T3, Fp1, Fp2, T4, O2), частота дискретизации ~125 Гц.
Для каждого испытуемого записано 6 файлов в формате EDF:
- `T-П.edf` — фоновая запись покоя с закрытыми глазами (~60 с);
- `T-1.edf` ... `T-5.edf` — пять последовательных сессий решения таблиц Шульте с открытыми глазами.

Целевая переменная: вероятность принадлежности к группе ПТСР в диапазоне [0, 1].

Основные группы:
- Контроль (норма): 67 испытуемых исходного выпуска, 40 дополнительных (только покой) и 23 нормы 65+;
- ПТСР: 25 испытуемых (клиническая верифицированная когорта);
- Соматоформные расстройства: 74 испытуемых (контроль специфичности).

Сдаваемая модель (протокол 8) — логистическая регрессия на 23 спектральных признаках покоя (O1, Fp1, Fp2, T3, T4). Валидация — leave-one-group-out по группам испытуемых с общими записями; весь выбор модели внутри фолдов.

## Результат (вне выборки, 229 испытуемых)

| Метрика | Значение |
| --- | --- |
| ROC-AUC ПТСР / нормы моложе 65 лет | 0.864 [0.796; 0.919] |
| ROC-AUC ПТСР / нормы без формата C | 0.765 [0.661; 0.862] |
| Чувствительность при 0.5 | 0.84 |
| Специфичность: нормы 65+ · соматоформные | 0.87 · 0.61 |

## Структура проекта

- `model/`
  - `model.py` — функции load, predict, run для инференса модели организаторами;
  - `requirements.txt` — зависимости Python.
- `results/`
  - `1-exploration.ipynb` — первичный анализ сигналов, спектров и поведенческих маркеров;
  - `2-preprocessing.ipynb` — фильтрация, извлечение признаков и обучение моделей;
  - `3-model-inference.ipynb` — расчет итоговых метрик (ROC-AUC с bootstrap 2000, Balanced Accuracy);
  - `4-confounders-specificity.ipynb` — анализ специфичности на соматоформных расстройствах и контроль возраста;
  - `5-metronome-bonus.ipynb` — ответ на метроном без меток стимулов, проверка на ERP CORE, MMN/P3a;
  - `validation/` — сохранённые результаты всех протоколов.
- `src/` — предобработка, признаки, модели, валидация, диагностика конфаундеров.
- `report/` — отчёт (`report.pdf`) и презентация (`presentation.pptx`, `presentation.pdf`).
- `docs/`
  - `DATA_AUDIT.md` — аудит данных и ход решения по протоколам;
  - `CLINICAL_INTERPRETATION.md` — клиническая и нейрофизиологическая интерпретация;
  - `TASK_SPEC.md` — требования ТЗ к решению.
- `download_data.py` — утилита для скачивания обучающего датасета из S3.

## Установка и запуск

Python 3.12.7. Установка зависимостей модели:
```bash
pip install -r model/requirements.txt
```

Для ноутбуков и тестов:
```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest
```

Загрузка обучающего датасета (`--remote` берёт актуальный листинг хранилища):
```bash
python download_data.py --remote
```

Инференс на тестовой папке (веса загружаются без переобучения, `src/` подключается из `model/model.py` автоматически):
```python
from pathlib import Path
from model.model import load, run

model = load(Path("model/weights"))
run(model, input_dir=Path("test_data"), output_path=Path("predictions.csv"))
```

`input_dir` содержит папки испытуемых; имена файлов `T-П.edf`, `T-1.edf` … распознаются независимо от регистра и кириллических/латинских букв `Т`/`T`. Пустые, отсутствующие и нечитаемые записи пропускаются; вероятность всегда конечна и лежит в [0, 1].

Переобучение с сырых данных (детерминированно: повторный запуск воспроизводит `model/weights/model.json` до округления):
```bash
python model/model.py --data-dir data --out model/weights
```
