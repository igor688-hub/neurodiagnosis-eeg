# Нейрофизиологическая диагностика ПТСР по данным малоканальной сухой ЭЭГ

Решение команды **bokom-m** в рамках хакатона по нейродиагностике посттравматического стрессового расстройства (ПТСР).

---

## 📌 Описание задачи

Разработка ML-решения для бинарной классификации и непрерывной оценки вероятности ПТСР по записям 6-канальной сухой ЭЭГ (гарнитура **NeuroPlay-6C**: каналы `O1`, `T3`, `Fp1`, `Fp2`, `T4`, `O2`).

### Ключевые требования и принципы:
- **Разбиение строго на уровне испытуемых**: исключение любых утечек данных (GroupKFold / Leave-One-Subject-Out).
- **Специфичность**: способность отличать специфический ПТСР-фенотип от других расстройств (соматоформные расстройства) и возрастных изменений (нормальное старение 65+).
- **Контроль конфаундеров**: проверка инвариантности к возрасту и поведенческим показателям (скорость выполнения таблиц Шульте).
- **Физиологическая интерпретируемость**: обоснованность каждого извлеченного признака с опорой на литературу по нейрофизиологии.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r model/requirements.txt
```

### 2. Загрузка данных
Для скачивания всех 996 файлов (~77 МБ) обучающего набора в папку `data/`:
```bash
python download_data.py
```

### 3. Запуск инференса
Функция инференса запускается через `model/model.py` с сохранением итогового CSV:
```python
from pathlib import Path
from model.model import load, run

model = load(Path("model/weights"))
run(model, input_dir=Path("path/to/test_subjects"), output_path=Path("predictions.csv"))
```
Формат выходного CSV:
```csv
subject_id,ptsd_probability
КС010_19,0.1245
34PHG,0.8712
```

## 📊 Валидация и метрики

- **ROC-AUC (ПТСР vs Контроль)** с 2000 итерациями бутстрэпа для расчета 95% доверительного интервала.
- **Сбалансированная точность (Balanced Accuracy)**.
- **Специфичность**: доля ложноположительных срабатываний на группах «Соматоформные расстройства» и «Нормальное старение».
